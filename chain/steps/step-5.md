# Step 5: Floating bubble, hotkey, notification, tile

Deliverables:
- `BubbleService` (foreground service, type specialUse or none as appropriate; keep a low-priority ongoing notification): draws a draggable circular mic bubble with `WindowManager` using `TYPE_APPLICATION_OVERLAY`, flags `FLAG_NOT_FOCUSABLE | FLAG_NOT_TOUCH_MODAL | FLAG_LAYOUT_NO_LIMITS`, so tapping it never steals focus from the text field. Tap toggles `VoiceController`; long-press or drag moves it; position saved per display. State visuals: idle (dim), recording (red pulse driven by amplitude), transcribing (spinner/amber), error (brief shake plus toast). Must be DISPLAY-AWARE for Samsung DeX: use `DisplayManager` to find displays; create a window context for the target display (`createWindowContext(display, TYPE_APPLICATION_OVERLAY, null)` or `createDisplayContext` + `WindowContext` on API 33+) and add the view there. Target display = the display the active IME window or input field is on (the IME instance can report `display?.displayId` / its window context). Re-evaluate when the IME starts input (`onStartInputView`) and on display add/remove/change events, moving the bubble to follow. Only show if overlay permission is granted; otherwise do nothing and let onboarding explain.
- `HotkeyAccessibilityService : AccessibilityService` configured via `res/xml/hotkey_service.xml` with `flagRequestFilterKeyEvents`, `canRequestFilterKeyEvents=true`, `canRetrieveWindowContent=false`, no event types needed. In `onKeyEvent`, match the saved combo (keyCode + modifier mask) on ACTION_DOWN, toggle `VoiceController`, and consume the event (return true) for the combo only; ignore key repeats; pass everything else through untouched. Default combo: Ctrl+Shift+Space (document that it is configurable). Add a `HotkeyCaptureActivity` ("Press your shortcut now") that stores the combo in Settings and warns if it conflicts with common combos. Also add manifest declaration with `BIND_ACCESSIBILITY_SERVICE` and a plain-language description string stating it ONLY listens for the shortcut and does not read the screen.
- Persistent control notification (notification channel; Start/Stop action broadcasting to a receiver that calls `VoiceController.toggle()`) managed by BubbleService or a small `ControlNotification` helper.
- `VoiceTileService : TileService` (Quick Settings tile "DeX Voice": toggles, reflects state).
- Settings additions: bubble on/off, hotkey capture button, "Start bubble on boot" optional (BOOT_COMPLETED receiver) default off.
- Unit tests for the hotkey matching logic (pure function over keyCode/metaState).

Done when: compiles, manifest attributes valid for API 34, hotkey matcher tests written and (if a local SDK exists) green, and no component reads window content.
